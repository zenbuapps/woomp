# Clarify Session 2026-03-23 18:30

## Idea

你可以做個紅燈 E2E 測試嗎?
分期 & 不分期 交易成功，應該都要能收到 webhook，訂單狀態 [處理中] 或 [已完成]
分期 & 不分期 交易失敗，訂單狀態都應該維持 [等待付款中]

## Q&A

- Q: 失敗場景如何驗證「未收到 webhook」？(A) 下單後等待 webhook 超時，再檢查訂單狀態為 pending (B) 直接檢查訂單狀態不變即可，不需等待 (C) 攔截 webhook endpoint 確認無請求 → A: A — 下單後等待一段時間確認 webhook 沒回來，超時後透過 WC REST API 驗證訂單狀態仍為 pending
