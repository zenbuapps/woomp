# 新卡片輸入表單

## 描述
PayUni SDK iframe 渲染的信用卡輸入欄位。卡片資訊不經過商店伺服器（PCI-DSS 合規）。

## 元素
- `#put_card_no` — 信用卡號碼（SDK iframe）
- `#put_card_exp` — 有效期限（SDK iframe）
- `#put_card_cvc` — 安全碼（SDK iframe）
- `#put_token_type` — 記憶卡號 checkbox 容器（由 SDK 根據 useTokenType 事件渲染）
- `#payuni_installment` — 分期付款下拉選單（若啟用）

## 驗證
- FormState 追蹤三個欄位的 valid/invalid 狀態
- 全部 valid 時才允許提交
- SDK 內部處理欄位格式驗證（卡號 Luhn 檢查、過期日、CVC 長度）

## 樣式
- iframe 預設樣式：color #333，fontSize 16px，errorColor #e53e3e
