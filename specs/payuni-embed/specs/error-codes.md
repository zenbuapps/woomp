# PayUni 錯誤代碼對應表

來源：`HttpClient::$error_mapper`（共 109 組）

## SDK 錯誤（前端 iframe）

| 代碼 | 訊息 | 說明 |
|------|------|------|
| 1000 | 尚未設定連動相關 div ID | SDK 初始化設定錯誤 |
| 1001 | iframe 連線失敗, 無法使用相關 function | iframe 無法建立連線 |
| 1002 | 無法使用分期, 在 PAYUNi 平台上沒有開啟分期選項 | 分期未啟用 |
| 1003 | 填寫分期數有誤，請重新確認 | 分期期數格式錯誤 |
| 1004 | function 帶入參數有誤，請重新確認 | SDK API 參數錯誤 |
| 1005 | 填寫欄位有誤，請重新確認 | SDK 表單驗證未通過 |
| 1006 | 沒有填寫 SDK token | SDK Token 未提供 |
| 1007 | 非法的跨域溝通，Token 設定的 限定網域名稱 與 當前網域端 不吻合 | 網域驗證失敗 |
| 1008 | iframe 嘗試連線時間過長, 中斷連線 (timeout) | iframe 連線逾時 |
| 1009 | iframe 無法取得當前網域, 中斷連線 (timeout) | 網域取得失敗 |

**前端特殊處理：**
- 1008 → 顯示「信用卡輸入框連線逾時，請重新整理頁面」
- 1007 → 顯示「網域驗證失敗，請聯繫網站管理員」
- 其他 → 查詢 ERROR_MAPPER 對應
