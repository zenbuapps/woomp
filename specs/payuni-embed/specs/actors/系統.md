# 系統

## 描述
Woomp WordPress 外掛 + WooCommerce 平台。負責結帳頁面渲染、SDK 初始化、交易加密與執行、訂單狀態管理、Token 儲存。

## 關鍵屬性
- 後端：PHP 8.1+，WooCommerce Payment Gateway API
- 前端：ES6 Modules，PayUni UNi Embed SDK iframe
- 加密：AES-256-GCM + SHA256 HMAC（EncryptUtils）
- 資料層：WooCommerce Order Meta、WC_Payment_Token 系統
- 日誌：WC_Logger，source tag 為 payuni_payment_v3
