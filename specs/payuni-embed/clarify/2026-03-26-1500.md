# Clarify Session 2026-03-26 15:00

## Idea

PayUni V3 定期定額閘道已完成實作。現在需要為 V3 訂閱訂單新增「手動扣款」功能，與 V1 的行為一致。

V1 現有手動扣款機制：三個檔案協作（Metabox.php + Ajax.php + admin.js）。
V3 需要做的：當訂單的 payment_method 為 payuni-credit-subscription-v3 時，也要在訂單詳情頁顯示手動扣款 metabox，並且用 V3 的 SubscriptionHandler::process_renewal_payment() 來執行扣款。

需要釐清：
1. V3 手動扣款是否複用 V1 的 Metabox/Ajax，還是另建新的？
2. Metabox 的 ID 和 title
3. HPOS 相容
4. 前端 JS

## Q&A

- Q: V3 手動扣款應該獨立實作還是擴展 V1 現有代碼？ → A: 選 A，獨立實作。在 V3 (`includes/payuni/v3/`) 新建 Metabox + Ajax handler，僅處理 payuni-credit-subscription-v3。
- Q: V3 手動扣款的 Metabox 取得訂單 ID 的方式是否需要同時支援 HPOS 和傳統模式？ → A: 選 A，雙模式相容，先 $_GET['id']（HPOS）再 fallback $_GET['post']（傳統）。
- Q: V3 手動扣款的前端 JS 是否複用 V1 的 admin.js 還是獨立建立？ → A: 選 B，獨立 JS + 獨立 AJAX action，完全解耦。
