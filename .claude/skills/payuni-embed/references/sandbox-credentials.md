# PAYUNi 沙箱測試環境

## 後台 URL

| 環境 | URL |
|------|-----|
| 測試區 | `https://sandbox.payuni.com.tw` |
| 正式區 | `https://www.payuni.com.tw` |

> 登入沙箱後台可查看：商店代號（MerID）、Hash Key、Hash IV、交易紀錄。

## 使用注意事項

- **到期日**：任意填入（如 `1228` 表示 12/28）
- **安全碼（CVC）**：任意三碼（如 `123`）
- 測試卡號**僅限沙箱環境**使用，請勿用於正式環境
- 支援的分期期數：3、6、9、12、18、24、30 期（視卡號而定）
- 支援卡別：Visa、MasterCard、JCB、銀聯卡

## 本地開發環境

本專案使用 Cloudflare Tunnel 將本地環境暴露給 PAYUNi：

- **本地測試域名**：`https://local-turbo.powerhouse.tw`
- **Webhook 通知 URL**（本地）：`https://local-turbo.powerhouse.tw/wc-api/payuni_notify`
- 當 `IFrameDomain` 偵測到本地環境時，自動替換為上述域名
