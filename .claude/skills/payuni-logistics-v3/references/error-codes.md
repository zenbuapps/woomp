# PAYUNi 物流相關錯誤代碼總表

> 來源：docs.payuni.com.tw 官方頁 `#/7/119`（物流相關錯誤代碼）+ `#/7/156`（所有 API 通用錯誤代碼）。爬取日 2026-05-04。

## 錯誤碼前綴速查

| 前綴 | 涵義 | 何時出現 |
|---|---|---|
| `API00xxx` | 通用 API 框架錯誤 | 加密 / 版本 / Token 層級 |
| `DEF01xxx` | 通用平台錯誤 | 商店狀態 / Hash / 解密失敗（跨產品共用） |
| `DEF05xxx` | 物流通用錯誤 | 商店物流設定、地址驗證 |
| `HOME01xxx` | 黑貓宅配相關錯誤 | `/api/home_delivery/*` 系列 |
| `LAB01xxx` ~ `LAB06xxx` | 超商出貨單列印（print_label） | `/api/logistics/print_label` 與相關 |
| `LGR01xxx` ~ `LGR06xxx` | 退貨便（refund / C2B） | `/api/logistics/refund` |
| `SHIP01xxx` ~ `SHIP07xxx` | 超商物流通用 | `/api/logistics/trade`、`/ship_map`、`/query`、`/update`、`/c2c_to_home_delivery` |

  // 業務錯誤：回給用戶調整
  return { retriable: false, userMessage: '請檢查物流資料', internalLog: 'warn' };
