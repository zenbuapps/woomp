# 列舉值（Enums）

> 來源：docs.payuni.com.tw 各 API 頁、`#/7/170` 訂單金額限制、`#/7/120` 物流貨態。

## LgsType — 物流型態

| Value | 中文名稱 | 用法 |
|---|---|---|
| `B2C` | 大宗寄倉 | 7-ELEVEN 超商：賣家寄到物流中心 → 配送門市 |
| `C2C` | 店到店 | 7-ELEVEN 超商：賣家在門市寄、買家在門市取（含交貨便+回頭便） |
| `HOME` | 黑貓宅配 | 黑貓宅配（正物流 + 退貨） |
| `C2B` | 退貨便 | 7-ELEVEN 超商退貨便（**僅 B2C 開通會員可用**） |

## GoodsType — 寄件溫層

| Value | 名稱 | 限制 |
|---|---|---|
| `1` | 常溫 | 全部 LgsType / ShipType 皆支援 |
| `2` | 冷凍 | 7-ELEVEN（B2C / C2C）、黑貓 |
| `3` | 冷藏 | **僅黑貓宅配 (HOME)** |

## ServiceType — 取件 / 退貨方式

| Value | 名稱 | 適用 |
|---|---|---|
| `1` | 取貨付款（COD） | trade（CVS / HOME）|
| `3` | 取貨不付款 | trade（CVS / HOME）；refund（HOME 固定 3）|
| `4` | 退貨付款 | refund（C2B 退貨便） |
| `5` | 退貨不付款 | refund（C2B 退貨便） |

## ShipType — 通路類別

| Value | 通路 |
|---|---|
| `1` | 7-ELEVEN |
| `2` | 黑貓宅配 |

> **注意**：PAYUNi 物流目前**僅支援 7-ELEVEN 與黑貓**。沒有全家、萊爾富、OK。

## Tag — ship_map 處理標記（**不是超商代號**）

| Value | 用途 |
|---|---|
| `2` | 回傳選取的門市資訊（首次選店）|
| `3` | 更新商店預設退貨門市（**僅 C2C**） |
| `4` | 更新指定物流單的取件門市（門市關轉重選）|
| `5` | 更新指定 C2C 物流單的退貨門市（門市關轉重選）|

> 用 Tag=4 或 5 時，`MerKeyNo` 必須帶 `ShipTradeNo`。

## MapType — 地圖涵蓋區域

| Value | 範圍 |
|---|---|
| `1` | 僅本島 |
| `2` | 本島含離島 |

> GoodsType=2（冷凍）時，MapType 固定 2。

## MobileTag — ship_map 裝置標記

| Value | 顯示版本 |
|---|---|
| `Y` | 手機版 |
| `N` | PC 版 |
| 不帶 | PC 版（預設） |

## DeliveryTimeTag — 黑貓希望配達時段

| Value | 時段 |
|---|---|
| `01` | 13 時前 |
| `02` | 14-18 時 |
| `04` | 不指定 |

## Spec — 黑貓宅配規格

| Value | 尺寸 | 冷凍冷藏支援 |
|---|---|---|
| `1` | 60 cm | 是 |
| `2` | 90 cm | 是 |
| `3` | 120 cm | 是 |
| `4` | 150 cm | **否，僅常溫** |

## TradeType — 黑貓宅配方向（query 與 trade 回傳）

| Value | 意義 |
|---|---|
| `1` | 正物流（一般宅配，從 trade 建立的單） |
| `2` | 逆物流（退貨，從 refund 建立的單） |

## TradeStatus — 訂單付款狀態

| Value | 意義 |
|---|---|
| `0` | 建立階段（剛產生物流單） |
| `1` | 取件付款完成（Notify 觸發） |

> 注意：**金流訂單** 的 TradeStatus 有更多值（0=等待付款 / 1=付款完成 / 2=失敗 / 3=取消 / 4=逾期 / 5=退款完成 / 6=取號失敗 / 8=待確認 / 9=未付款），詳見 `payuni-upp-v3` 或 `payuni-upp-v2` SKILL。物流單的 TradeStatus 只用 0 / 1。

## PaymentType — 支付方式（建立物流單回傳 + Notify）

| Value | 支付工具 |
|---|---|
| `0` | 取貨不付款（ServiceType=3 時 trade 回傳）|
| `1` | 信用卡 |
| `2` | ATM 轉帳 |
| `3` | 超商代碼 |
| `5` | 取貨付款（CVS）|
| `6` | 愛金卡 (icashPay) |
| `7` | 後支付 (AFTEE) |
| `8` | 退貨代收 |
| `10` | 宅配到付（HOME COD）|
| `11` | 街口支付 (JKoPay) |

## CarrierType — 發票載具

| Value | 載具 | CarrierInfo 內容 |
|---|---|---|
| `3J0002` | 手機條碼 | `/AB12345`（含 /） |
| `CQ0001` | 自然人憑證 | 條碼 |
| `amego` | 會員載具 | 免填（用 UsrMail）|
| `Donate` | 捐贈碼 | 例如 `25885` |
| `Company` | 公司發票 | 統編 8 碼 |

## 訂單金額限制（page #/7/170）

| 支付工具 | 上下限 |
|---|---|
| 信用卡 | 1~199,999 元 |
| ATM 轉帳 | 15~49,999 |
| 超商代碼 | 30~20,000 |
| icash Pay | 依 icashPay 公告 |
| AFTEE 先享後付 | 20~49,999 |
| **CVS 取貨付款（B2C / C2C）** | **1~20,000** |
| LINE Pay | 依 LINE Pay 公告 |
| 街口支付 | 依街口公告 |
| **黑貓貨到付款** | **30~20,000** |

## 超商代碼（page #/7/51）

PAYUNi 物流的「超商代碼（英文）」目前**只有一個**：

| 代碼 | 中文 |
|---|---|
| `SEVEN` | 統一超商 (7-11) |

> 出現在 ship_map 回傳 `MapJson.StoreType`。
