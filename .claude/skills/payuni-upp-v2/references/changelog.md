# PAYUNi 修改記錄（2022-08 至今）

> 來源：[#/7/25 修改記錄](https://docs.payuni.com.tw/web/#/7/25)（逐字保留）
>
> **重點**：UPP 自 **2026/01/05** 升版為 `Ver 2.0`（配合優惠券功能新增），1.0 版本仍可正常使用。本 SKILL 對應 V2.0，並標註 V2.0 對應的舊版 V1.0 行為差異。
