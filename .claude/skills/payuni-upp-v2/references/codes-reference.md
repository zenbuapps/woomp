## 信用卡交易狀態說明

> 來源：[#/7/153](https://docs.payuni.com.tw/web/#/7/153)

商店信用卡請款設定影響交易狀態：

| 商店設定 | 交易完成狀態 |
|---------|------------|
| 自動請款（預設） | 授權成功 → 自動進入請款狀態 |
| 手動請款 | 授權成功 → 等待商店發起 `/api/trade/close` `CloseType=1` |

請款狀態（`CloseStatus`）：
- `1`=請款申請中
- `2`=請款成功
- `3`=請款取消
- `7`=請款處理中
- `9`=未申請

退款狀態（`RefundStatus`）：
- `1`=退款申請中
- `2`=退款成功
- `3`=退款取消
- `8`=退款處理中

時程：
- 請款天期：授權成功後 **3 天內**請款（逾期銀行可能拒絕）
- 退款天期：請款完成後 **180 天內**退款

## 訂單金額限制

| 支付工具 | 金額範圍（TWD）|
|---------|------|
| 信用卡 | 1 ~ 199,999 |
| ATM 轉帳 | 15 ~ 49,999 |
| 超商代碼 | 30 ~ 20,000 |
| AFTEE 先享後付 | 20 ~ 49,999 |
| 貨到付款（超商取貨）| 1 ~ 20,000 |
| 宅配貨到付款（黑貓）| 30 ~ 20,000 |
| icash Pay | 依 icash Pay 公告 |
| LINE Pay | 依 LINE Pay 公告 |
| 街口支付 | 依街口支付公告 |

> 超出限額會回傳 `UPP02088`-`UPP02108` 等「此交易金額無法使用」錯誤碼。
